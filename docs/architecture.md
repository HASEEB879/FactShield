# FactShield Architecture

## Overview

FactShield consists of five major components.

1. Frontend (Web)
2. Mobile App
3. Backend API
4. AI Engine
5. Database

---

## Frontend

Technology

- Next.js
- React
- TypeScript

Responsibilities

- Landing Page
- Dashboard
- Authentication
- Fact Check Interface

---

## Mobile

Technology

- Flutter

Responsibilities

- Android App
- Notifications
- Camera Integration
- Share Extension

---

## Backend

Technology

- FastAPI

Responsibilities

- Authentication
- API
- Fact Checking Pipeline
- User Management

---

## AI Engine

Responsibilities

- Claim Analysis
- Source Discovery
- Evidence Ranking
- Confidence Score
- Explanation Generation

---

## Database

Technology

- PostgreSQL
- Supabase

Stores

- Users
- Searches
- Reports
- Saved Claims
